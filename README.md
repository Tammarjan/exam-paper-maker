# Exam Paper Maker

Offline-first exam paper creator for teachers. No Cloudflare or server is required after installation.

## Build Android APK
1. Open the Actions tab.
2. Select Build Android APK and tap Run workflow.
3. Download the exam-paper-maker-debug-apk artifact when the workflow completes.
4. Extract the ZIP on Android and install app-debug.apk.

The APK bundles the app files for offline use. This is a debug build for testing; signed release packaging can be added later. Paper data stays on the device. Export backups before clearing app data or changing phones.
